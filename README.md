# 🐾 Concurso de Mascotes 2026 — IFRO Campus Ariquemes

Galeria digital das propostas homologadas do **Concurso de Mascotes dos Cursos do Instituto Federal de Rondônia (IFRO) — Campus Ariquemes**, edição 2026.

O site permite selecionar um curso, conhecer os mascotes participantes, visualizar suas ilustrações e ler as justificativas das propostas.

### 🌐 Acesse a galeria

**[Conhecer os mascotes](https://wallisonstorck.github.io/mascotes-ifro-2026/)**

### 🗳️ Votação

A votação será realizada pelo **SUAP**, sistema institucional do IFRO. O link será divulgado oportunamente.

### 🛠️ Tecnologias

HTML, CSS e JavaScript, com publicação pelo **GitHub Pages**. Os dados das propostas estão em `mascotes.json` e as ilustrações na pasta `images/`.
